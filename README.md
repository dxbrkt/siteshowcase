# Классика-АГ

Многостраничный сайт на Astro. Статическая сборка, общий шаблон страниц и TypeScript для данных и компонентов. Дизайн и тексты перенесены из предыдущей версии.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Сайт: http://localhost:3000. Изменения исходников видны сразу. `npm start` — тот же режим разработки. Если остался запущен старый сервер, сначала остановите его через Ctrl+C.

## Где что менять

| Задача | Файл или папка |
| --- | --- |
| Главная | `src/pages/index.astro` |
| Обычные страницы | `src/pages/*.astro` |
| Каталог услуг | `src/pages/uslugi/index.astro` |
| Шаблон всех услуг | `src/pages/uslugi/[slug].astro` |
| Тексты и тарифы услуг | `src/data/services.ts` |
| Отзывы, документы и цены калькулятора | `src/data/` |
| Шапка, подвал, логотип, карточки | `src/components/` |
| Общая оболочка и метаданные страниц | `src/layouts/BaseLayout.astro` |
| Общие стили и адаптивность | `src/styles/` |
| Меню, калькулятор, формы, просмотр фото | `src/scripts/` |
| Изображения | `public/assets/images/` |

Каждая услуга — запись в `services.ts`. Её `slug` задаёт адрес; отдельную папку или копию страницы создавать не нужно. При изменении адресов учитывайте существующие внешние ссылки.

## Проверка и сборка

```sh
npm run check
npm run build
npm run preview
```

`dist/` — автоматически созданный сайт для хостинга. Его не редактируют и не коммитят. Папки `dist`, `.astro` и `node_modules` скрыты в проводнике VS Code. Исходники лежат в `src` и `public`.

`npm run format` форматирует исходники. Рекомендуемые расширения VS Code указаны в `.vscode/extensions.json`.

## GitHub Pages

В репозитории выберите Settings → Pages → Source → GitHub Actions. Workflow `pages.yml` устанавливает зависимости, проверяет и собирает сайт после push в `main`, затем публикует `dist`.

Путь репозитория и адрес сайта берутся из настроек GitHub Pages автоматически. Для другого статического хостинга достаточно загрузить содержимое `dist`.

Для ручной сборки в подпапку:

```sh
BASE_PATH=/repository-name SITE_URL=https://username.github.io npm run build
```

В компонентах используйте `withBase()` для внутренних ссылок и изображений — это сохраняет работу сайта в подпапке.

## Заявки

Форма открывает почтовую программу через `mailto:`. Серверной отправки заявок сейчас нет. Калькулятор выдаёт предварительный расчёт и переносит его в форму контактов.
